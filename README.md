# NexaCraft Digital Studio

**We build digital experiences powered by AI.**

Premium 3D digital-agency website — built with React, Three.js (React Three Fiber), GSAP, Lenis, Tailwind CSS and Vite.

## What's inside

- Interactive WebGL hero scene with mouse parallax and scroll-reactive motion
- AI-agent pipeline visualization with a live 3D agent core
- Runnable n8n-style automation workflow demo
- AI website-integration transformation flow
- Interactive custom-agent builder preview with live terminal
- Scroll-triggered cinematic process timeline
- Filterable concept portfolio, tech stack, and lead CTAs
- Reduced-motion and no-WebGL graceful fallbacks
- SEO: meta, Open Graph, sitemap, robots

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Pushes to `main` deploy automatically to GitHub Pages via GitHub Actions.
